# Skill HITL Acceptance Records

Create one file per skill only when `SKILL.md` exceeds 200 LOC and remains below 300 LOC.

## File path

```text
docs/skill-hitl-acceptance/<skill-name>.md
```

## Required template

```yaml
skill: <skill-name>
accepted_by: <human reviewer>
accepted_at: YYYY-MM-DDTHH:MM:SS-04:00
decision: accepted
reason: <why this skill is allowed to exceed 200 LOC>
review_scope: <what was reviewed>
follow_up: <refactor plan or N/A>
```

## Policy

- 201-299 LOC requires human review and timestamped acceptance.
- 300+ LOC must be refactored before merge.
- Acceptance records are not auto-generated by agents.
- The human reviewer owns the acceptance timestamp and reason.
