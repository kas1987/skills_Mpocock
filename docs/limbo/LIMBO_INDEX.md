# Limbo Index

This folder captures ideas, comments, contradictions, enhancements, and possible future scope that should not immediately mutate the active Mission, Bead, or proof gate.

## Status buckets

| Bucket | Meaning |
| --- | --- |
| `intake/` | New untriaged or parked ideas |
| `promoted/` | Ideas converted into Missions, Beads, ADRs, or active tasks |
| `rejected/` | Ideas intentionally discarded with reason |
| `deferred/` | Ideas kept for later review |
